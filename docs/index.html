How to use it

  1. Start on 🏠 Home. The roadmap goes Foundations → Systems and networks → Security and cloud → Specialize → Senior, with Japanese alongside. Home also shows which languages your computer can run.
  2. Open a track and read a lesson. Press Run on any code example and change it to see what happens.
  3. Do the quiz and the exercises. Exercises are checked automatically. Ask for a hint before looking at the solution.
  4. Build the projects. Each project card can create the files in ITQuestProjects next to the app, open them in VS Code, and run the commands in a terminal. Projects are what you show in job interviews.
  5. Review every day. 🃏 Review gives you flashcards with spaced repetition and practice exams for every track.

Set up the AI helper (optional)

  1. Install Ollama (or LM Studio).
  2. Download a model: ollama pull qwen2.5-coder:7b
  3. In IT Quest, open 🤖 AI Helper. The default address http://localhost:11434/v1 works for Ollama (LM Studio: http://localhost:1234/v1). Choose the model.

Everything stays on your computer. Keep Hints only on while you practise. When you ask, the helper can change the code in the editor and your project files, run or check it, and read the result; every change can be undone.

For future AI assistants and contributors

The repository is set up so that an AI coding assistant (or a person) can add lessons, projects and tracks safely. Start with AGENTS.md.

Where things live

Lessons are text files in content/<track>/, registered in src-tauri/src/tracks.rs. The Rust backend runs code; the React UI is in src/.

Golden rules

Never rename lesson ids or reorder exercises (they are progress keys). Every change must pass --verify with 0 problems.

Tools

tools/assemble.py and tools/stub.py build guided projects; tools/project_ideas/ generates project briefs from specs.

# check everything (runs examples, exercise solutions and project tests)
cd src-tauri
CARGO_TARGET_DIR=target/verify cargo run -q -- --verify --projects

# release: bump the version in package.json, tauri.conf.json and Cargo.toml, then
git push origin release   # GitHub Actions builds Windows + Linux and publishes the release
