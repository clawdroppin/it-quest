## Business email (ビジネスメール)

Japanese business emails follow a fixed structure. Get it right and people forgive grammar mistakes.

```text
件名: 【障害報告】社内ファイルサーバーへの接続不可について (第1報)

株式会社〇〇
情報システム部 佐藤様

いつもお世話になっております。
△△株式会社の□□です。

本日10時頃より、社内ファイルサーバーに接続できない障害が発生しております。

■ 発生日時: 2026年10月30日 10:05頃
■ 影響範囲: 本社3階の全端末 (約50台)
■ 現在の状況: 原因を調査中です。
■ 暫定対応: 共有フォルダのデータは、SharePoint からご利用いただけます。
■ 次回報告: 12時までにご連絡いたします。

ご迷惑をおかけし、大変申し訳ございません。
引き続きよろしくお願いいたします。

――――――――――
△△株式会社 運用サポート部
□□ (Name)
TEL: 03-xxxx-xxxx
――――――――――
```

| Part | Notes |
|---|---|
| **件名** (subject) | specific; 【】 brackets for type: 【ご報告】【ご依頼】【至急】 |
| **宛名** | company, department, name + **様** (sama); internally 〇〇さん |
| **挨拶** | external: **いつもお世話になっております**; internal: **お疲れ様です** |
| **名乗り** | who you are: 〇〇社の□□です |
| **本文** | conclusion first, then details; ■ bullets for facts |
| **結び** | **よろしくお願いいたします** (always) |
| **署名** | signature block |

An **incident report** (障害報告) gives: 発生日時 (when), 影響範囲 (impact), 現象 (symptoms), 原因 (cause), 対応内容 (what was done), 今後の対応 / 再発防止策 (next steps / prevention). First report fast (第1報), updates regularly (第2報...), final report (最終報) after.

## Chat (Teams / Slack)

Shorter and less formal than email, but still polite: start with **お疲れ様です**, mention people with @, and keep messages self-contained.

- 「お疲れ様です。〇〇の件、確認しました。問題ありません。」 (Checked the 〇〇 matter. No problems.)
- 「すみません、ちょっとご相談させてください。」 (Sorry, may I consult you about something?)
- 「対応中です。15時までに状況を共有します。」 (Working on it. I'll share the status by 15:00.)
- 「ありがとうございます!助かります。」 (Thanks! That helps a lot.)

## The phone (電話)

| Situation | Phrase |
|---|---|
| Answering | はい、〇〇株式会社 情報システム部の□□でございます。 |
| Thanking | お電話ありがとうございます。 |
| Confirming the caller | 恐れ入りますが、お名前を伺ってもよろしいでしょうか。 |
| Didn't catch it | 申し訳ございません、もう一度おっしゃっていただけますか。 |
| Putting on hold | 少々お待ちください。 |
| Calling back | 確認して、折り返しお電話いたします。 |
| Ending | 失礼いたします。 (Wait for the caller to hang up first.) |

## Help desk Japanese (ヘルプデスク)

| Japanese | Meaning |
|---|---|
| どのような症状でしょうか。 | What are the symptoms? |
| 画面に何と表示されていますか。 | What does the screen say? |
| エラーメッセージを教えていただけますか。 | Could you tell me the error message? |
| いつ頃から発生していますか。 | Since when has it been happening? |
| 他の方も同じ状況でしょうか。 | Are others having the same problem? (切り分け!) |
| 一度、再起動していただけますか。 | Could you restart it once? |
| リモートで接続してもよろしいでしょうか。 | May I connect remotely? |
| 画面を共有していただけますか。 | Could you share your screen? |
| 解決しましたので、チケットをクローズいたします。 | It's resolved, so I'll close the ticket. |

**〜ていただけますか** (could you please...) is the help desk's most useful pattern.

@@hint
`build` returns the list [company, person + "様", GREETINGS[relationship], f"{my_company}の{name}です。", *body, CLOSINGS[0], signature]. `check` looks at line 2 for 様 (or 御中, which goes on a company with no person), at line 3 for one of the greetings, and for a closing anywhere with `any(line.endswith(c) for c in CLOSINGS)`.
@@solution
GREETINGS = {"first contact": "突然のご連絡失礼いたします。", "existing client": "いつもお世話になっております。", "internal": "お疲れ様です。"}
CLOSINGS = ("よろしくお願いいたします。", "よろしくお願い申し上げます。")
drafts = {
    "good": ["株式会社ABC", "鈴木様", "いつもお世話になっております。", "XYZ株式会社の田中です。", "メンテナンス日程についてご連絡いたします。", "何卒よろしくお願いいたします。", "田中"],
    "no 様": ["株式会社ABC", "鈴木", "いつもお世話になっております。", "XYZ株式会社の田中です。", "資料を送付いたします。", "よろしくお願いいたします。", "田中"],
    "casual": ["株式会社ABC", "鈴木様", "こんにちは！", "田中です。", "資料送ります。", "田中"],
}

def build(company, person, relationship, me, body):
    my_company, name = me
    return [company, f"{person}様", GREETINGS[relationship], f"{my_company}の{name}です。", *body, CLOSINGS[0], f"{my_company} {name}"]

def check(lines):
    problems = []
    if not (lines[1].endswith("様") or lines[1].endswith("御中")):
        problems.append("recipient needs 様 (or 御中 for a company)")
    if lines[2] not in GREETINGS.values():
        problems.append(f"opening 「{lines[2]}」 is too casual; use 「{GREETINGS['existing client']}」")
    if not any(line.endswith(c) for line in lines for c in CLOSINGS):
        problems.append("no closing such as 「よろしくお願いいたします。」")
    return problems

email = build("株式会社ABC", "鈴木", "first contact", ("XYZ株式会社", "スミス"), ["求人情報を拝見し、ご連絡いたしました。", "履歴書を添付いたします。"])
print("\n".join(email))
print("--")
for name, lines in drafts.items():
    problems = check(lines)
    print(f"{name}: {'ok' if not problems else '; '.join(problems)}")
