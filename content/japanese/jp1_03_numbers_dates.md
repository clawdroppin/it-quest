@@lesson jp1-numbers-dates Numbers, Money, Dates and Times
@@text
Ticket numbers, prices in quotes, server counts, maintenance windows, meeting times: work Japanese is full of numbers, and they have two traps. Large numbers group by **four digits** (万 = 10,000, 億 = 100,000,000), not three; and dates, times and counters have irregular readings. Getting 四日 (よっか, the 4th) or 9時 (くじ) wrong in a phone call about a maintenance window causes real problems.

## Numbers up to 9,999

| | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|---|
| ones | いち | に | さん | よん | ご | ろく | なな | はち | きゅう |
| ×10 | じゅう | にじゅう | さんじゅう | よんじゅう | ごじゅう | ろくじゅう | ななじゅう | はちじゅう | きゅうじゅう |
| ×100 | ひゃく | にひゃく | さん**びゃく** | よんひゃく | ごひゃく | ろっ**ぴゃく** | ななひゃく | はっ**ぴゃく** | きゅうひゃく |
| ×1000 | せん | にせん | さん**ぜん** | よんせん | ごせん | ろくせん | ななせん | はっ**せん** | きゅうせん |

(4 and 7 also have readings し and しち, used in some fixed words; for counting money and quantities use よん and なな.)

## 万, 億, 兆: grouping by four

- 1万 = 10,000 (いちまん); 10万 = 100,000 (じゅうまん); 100万 = 1,000,000 (ひゃくまん); 1000万 = 10,000,000 (いっせんまん).
- 1億 = 100,000,000 (いちおく); 1兆 = 10¹² (いっちょう).
- Read 12,345,678 as **1234万5678**: せんにひゃくさんじゅうよんまん ごせんろっぴゃくななじゅうはち. (いっせん is used when 1000 stands alone before 万/億: いっせんまん.)
- Prices: ¥3,500,000 = 350万円 (さんびゃくごじゅうまんえん). Annual salaries are usually given in 万円: 年収500万円.

## Dates

| Day | Reading | Day | Reading |
|---|---|---|---|
| 1日 | **ついたち** | 6日 | **むいか** |
| 2日 | **ふつか** | 7日 | **なのか** |
| 3日 | **みっか** | 8日 | **ようか** |
| 4日 | **よっか** | 9日 | **ここのか** |
| 5日 | **いつか** | 10日 | **とおか** |
| 14日 | じゅう**よっか** | 20日 | **はつか** |
| 24日 | にじゅう**よっか** | others | number + にち (17 じゅうしちにち, 19 じゅうくにち) |

Months: number + がつ, with **4月 しがつ, 7月 しちがつ, 9月 くがつ**. Weekdays: 月曜日 げつようび, 火 か, 水 すい, 木 もく, 金 きん, 土 ど, 日 にち. Dates are written year/month/day: 2026年11月4日(水).

## Times

- 時 (o'clock): **4時 よじ, 7時 しちじ, 9時 くじ**; others regular (いちじ, にじ...).
- 分 (minutes): 1 いっ**ぷん**, 3 さん**ぷん**, 4 よん**ぷん**, 6 ろっ**ぷん**, 8 はっ**ぷん**, 10 じゅっ**ぷん**; 2, 5, 7, 9 use **ふん** (にふん, ごふん, ななふん, きゅうふん). Tens: 20 にじゅっぷん, 30 さんじゅっぷん; 30 minutes past is also 半 (はん).
- Business uses the 24-hour clock in writing (22:00〜翌2:00 = 22:00 until 2:00 the next day) and 午前/午後 (a.m./p.m.) in speech.

## Counters you'll need

台 (machines: サーバー3台), 件 (cases/tickets: 問い合わせ5件), 人 (people: ひとり, ふたり, then さんにん...), 回 (times), 個 (small items), 枚 (flat things: paper, cards, screenshots), 本 (long things, also phone calls: 電話1本).

Split the number into 4-digit groups with `divmod(n, 10000)`. `read_group(n, before_unit)` reads 1–9999: thousands (`THOUSANDS.get(d, DIGITS[d] + "せん")`, but `いっせん` when the whole group is exactly 1000 and `before_unit`), hundreds, tens (`じゅう`, with a digit prefix if > 1), ones. いち before ちょう becomes いっ.
@@solution
DIGITS = ["", "いち", "に", "さん", "よん", "ご", "ろく", "なな", "はち", "きゅう"]
HUNDREDS = {1: "ひゃく", 3: "さんびゃく", 6: "ろっぴゃく", 8: "はっぴゃく"}
THOUSANDS = {1: "せん", 3: "さんぜん", 8: "はっせん"}
UNITS = [("", ""), ("万", "まん"), ("億", "おく"), ("兆", "ちょう")]
numbers = [7, 48, 300, 1_986, 10_000, 3_500_000, 12_345_678, 10_000_000, 180_000_000, 1_000_000_000_000]

def read_group(n, before_unit):
    th, rest = divmod(n, 1000)
    h, rest = divmod(rest, 100)
    t, o = divmod(rest, 10)
    out = ""
    if th:
        out += "いっせん" if n == 1000 and before_unit else THOUSANDS.get(th, DIGITS[th] + "せん")
    if h:
        out += HUNDREDS.get(h, DIGITS[h] + "ひゃく")
    if t:
        out += ("" if t == 1 else DIGITS[t]) + "じゅう"
    out += DIGITS[o]
    return out

def japanese(n):
    if n == 0:
        return "0", "ぜろ"
    groups = []
    while n:
        n, g = divmod(n, 10000)
        groups.append(g)
    written, spoken = "", ""
    for i in range(len(groups) - 1, -1, -1):
        g = groups[i]
        if not g:
            continue
        kanji, kana = UNITS[i]
        written += f"{g:,}" + kanji
        reading = read_group(g, i > 0)
        if kana == "ちょう" and g == 1:
            reading = "いっ"
        spoken += reading + kana
    return written, spoken

for n in numbers:
    written, spoken = japanese(n)
    print(f"{n:>17,} = {written:<16} {spoken}")

from datetime import datetime

DAY_SPECIAL = {1: "ついたち", 2: "ふつか", 3: "みっか", 4: "よっか", 5: "いつか", 6: "むいか", 7: "なのか", 8: "ようか", 9: "ここのか", 10: "とおか", 14: "じゅうよっか", 20: "はつか", 24: "にじゅうよっか"}
NUM = ["", "いち", "に", "さん", "よん", "ご", "ろく", "なな", "はち", "きゅう", "じゅう", "じゅういち", "じゅうに"]
WEEKDAYS = [("月", "げつ"), ("火", "か"), ("水", "すい"), ("木", "もく"), ("金", "きん"), ("土", "ど"), ("日", "にち")]
windows = [("2026-11-04 22:30", "2026-11-05 01:00"), ("2026-12-20 09:00", "2026-12-20 17:45"), ("2027-04-01 04:00", "2027-04-01 07:10"), ("2027-07-14 19:00", "2027-07-15 06:06")]

def tens_ones(n, seven="なな", nine="きゅう", four="よん"):
    t, o = divmod(n, 10)
    ones = {4: four, 7: seven, 9: nine}.get(o, NUM[o])
    return ("" if t == 0 else ("" if t == 1 else NUM[t]) + "じゅう") + ones

def day_reading(d):
    return DAY_SPECIAL.get(d) or tens_ones(d, "しち", "く") + "にち"

def month_reading(m):
    return {4: "し", 7: "しち", 9: "く"}.get(m, NUM[m]) + "がつ"

def hour_reading(h):
    return "れいじ" if h == 0 else tens_ones(h, "しち", "く", "よ") + "じ"

def minute_reading(m):
    if m == 0:
        return ""
    t, o = divmod(m, 10)
    prefix = "" if t == 0 else ("" if t == 1 else NUM[t]) + "じゅ"
    if o == 0:
        return prefix + "っぷん"
    if t and o:
        prefix += "う"
    ones = {1: "いっぷん", 2: "にふん", 3: "さんぷん", 4: "よんぷん", 5: "ごふん", 6: "ろっぷん", 7: "ななふん", 8: "はっぷん", 9: "きゅうふん"}[o]
    return prefix + ones

def time_text(dt, next_day):
    written = ("翌" if next_day else "") + f"{dt.hour}時" + (f"{dt.minute}分" if dt.minute else "")
    spoken = ("よく" if next_day else "") + hour_reading(dt.hour) + minute_reading(dt.minute)
    return written, spoken

for start_s, end_s in windows:
    start, end = datetime.strptime(start_s, "%Y-%m-%d %H:%M"), datetime.strptime(end_s, "%Y-%m-%d %H:%M")
    wd, wd_kana = WEEKDAYS[start.weekday()]
    date_w = f"{start.month}月{start.day}日({wd})"
    date_s = f"{month_reading(start.month)}{day_reading(start.day)}({wd_kana}ようび)"
    sw, ss = time_text(start, False)
    ew, es = time_text(end, end.date() > start.date())
    print(f"{date_w} {sw}〜{ew}")
    print(f"  {date_s} {ss}から{es}まで")
