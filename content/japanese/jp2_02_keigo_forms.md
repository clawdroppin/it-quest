@@lesson jp2-keigo-forms 敬語 Forms: 尊敬語, 謙譲語 and the Phrases of Support Work
@@text
In 敬語 (honorific language), you raise the other person's actions with **尊敬語** (sonkeigo, respectful language) and lower your own with **謙譲語** (kenjōgo, humble language), all wrapped in **丁寧語** (teineigo, です/ます). Customers, managers and other companies get keigo; using a humble verb for a customer's action (or a respectful verb for your own) is the classic mistake. Most verbs follow two patterns; about a dozen common ones have special forms you must memorise.

## The patterns

| | Pattern | Example (待つ, wait) | Example (連絡する, contact) |
|---|---|---|---|
| 尊敬語 (their action) | **お + ます-stem + になる** | お待ちになる | **ご**連絡になる |
| 謙譲語 (my action) | **お + ます-stem + する** | お待ちする | **ご**連絡する |
| Respectful request | お + stem + ください | お待ちください | ご連絡ください |

Native Japanese verbs take **お**; Sino-Japanese する nouns (漢語) take **ご** (ご確認, ご連絡, ご説明, ご案内), with common exceptions such as お電話, お返事 (also ご返事).

Polite ます forms: なる → なります, する → します (お待ちしております is the very common "we look forward to it / we'll be waiting").

## Special verbs (memorise these)

| Plain | 尊敬語 (their action) | 謙譲語 (my action) |
|---|---|---|
| いる (be) | いらっしゃる | おる |
| 行く (go) | いらっしゃる | 参る / 伺う (visit) |
| 来る (come) | いらっしゃる / お越しになる | 参る |
| 言う (say) | おっしゃる | 申す / 申し上げる |
| する (do) | なさる | いたす |
| 見る (see) | ご覧になる | 拝見する |
| 食べる・飲む | 召し上がる | いただく |
| 知っている | ご存じだ | 存じている (存じております) |
| 聞く (hear/ask) | お聞きになる | 伺う / 拝聴する |
| 会う (meet) | お会いになる | お目にかかる |
| くれる / もらう / あげる | くださる / — / — | — / いただく / 差し上げる |

The five verbs いらっしゃる, おっしゃる, なさる, くださる, ござる take **い** (not り) before ます: いらっしゃ**い**ます, おっしゃ**い**ます, なさ**い**ます, くださ**い**ます, ござ**い**ます.

## Common mistakes

- **二重敬語** (double keigo): おっしゃられる, ご覧になられる: one honorific is enough (おっしゃる, ご覧になる).
- Using 謙譲語 for the customer: ×「受付で伺ってください」→ ○「受付でお尋ねください」.
- About your own company to outsiders, use humble forms and drop さん from colleagues' names: 「佐藤は席を外しております」 (Sato is away from their desk).
- **ご苦労様** is for those below you; to peers and superiors use **お疲れ様です**.

## Support phrases you'll use daily

| Phrase | Meaning |
|---|---|
| 少々お待ちください | please wait a moment |
| 確認いたします | I'll check (humble) |
| 折り返しご連絡いたします | I'll call/write you back |
| ご不便をおかけして申し訳ございません | sorry for the inconvenience |
| ご確認いただけますでしょうか | could you please check? |
| かしこまりました / 承知いたしました | certainly / understood |
| 恐れ入りますが | I'm sorry to trouble you, but… |
| 念のため | just to be sure |

@@hint
`masu(verb)` turns any keigo verb into its ます form: する endings → します; I_VERBS → drop る + います; なる/がる/参る/申す/おる etc. are group 1 (る → ります, す → します, く → きます); いる/いただく... treat by the last kana with I_ROW. For the patterns, the ます-stem of a group 1 verb is `verb[:-1] + I_ROW[verb[-1]]`, of a group 2 verb `verb[:-1]`.
@@solution
I_ROW = {"う": "い", "く": "き", "ぐ": "ぎ", "す": "し", "つ": "ち", "ぬ": "に", "ぶ": "び", "む": "み", "る": "り"}
SPECIAL = {
    "いる": ("いらっしゃる", "おる"), "行く": ("いらっしゃる", "参る"), "来る": ("いらっしゃる", "参る"),
    "言う": ("おっしゃる", "申す"), "する": ("なさる", "いたす"), "見る": ("ご覧になる", "拝見する"),
    "食べる": ("召し上がる", "いただく"), "会う": ("お会いになる", "お目にかかる"),
}
I_VERBS = {"いらっしゃる", "おっしゃる", "なさる", "くださる", "ござる"}
verbs = [("いる", 2), ("行く", 1), ("言う", 1), ("する", 3), ("見る", 2), ("食べる", 2), ("会う", 1),
         ("待つ", 1), ("書く", 1), ("調べる", 2), ("連絡する", 3), ("確認する", 3), ("説明する", 3)]

def masu(verb):
    if verb.endswith("する"):
        return verb[:-2] + "します"
    if verb in I_VERBS:
        return verb[:-1] + "います"
    return verb[:-1] + I_ROW[verb[-1]] + "ます"

def stem(verb, group):
    return verb[:-1] if group == 2 else verb[:-1] + I_ROW[verb[-1]]

def keigo(verb, group):
    if verb in SPECIAL:
        return SPECIAL[verb]
    if group == 3 and verb.endswith("する"):
        noun = verb[:-2]
        return "ご" + noun + "になる", "ご" + noun + "する"
    s = stem(verb, group)
    return "お" + s + "になる", "お" + s + "する"

print("plain       尊敬語 (their action)    謙譲語 (my action)")
for verb, group in verbs:
    respectful, humble = keigo(verb, group)
    print(f"{verb:<8} {masu(respectful):<16} {masu(humble)}")

sentences = [
    ("customer", "部長がおっしゃられたとおり、明日対応します。"),
    ("customer", "詳しくは受付で伺ってください。"),
    ("superior", "ご苦労様です。資料をお送りしました。"),
    ("customer", "資料をご覧になられましたか。"),
    ("customer", "少々お待ちください。確認いたします。"),
    ("customer", "こちらの画面を拝見してください。"),
]
DOUBLE = {"おっしゃられ": "おっしゃっ", "ご覧になられ": "ご覧になり"}
HUMBLE_REQUESTS = {"伺ってください": "お尋ねください", "参ってください": "お越しください", "拝見してください": "ご覧ください"}

def check(audience, sentence):
    problems = []
    for wrong, right in DOUBLE.items():
        if wrong in sentence:
            problems.append(("double keigo", sentence.replace(wrong, right)))
    for wrong, right in HUMBLE_REQUESTS.items():
        if wrong in sentence:
            problems.append(("humble verb for the customer's action", sentence.replace(wrong, right)))
    if "ご苦労様" in sentence and audience in ("superior", "customer"):
        problems.append(("ご苦労様 is for people below you", sentence.replace("ご苦労様", "お疲れ様")))
    return problems

for audience, sentence in sentences:
    problems = check(audience, sentence)
    if not problems:
        print(f"OK  {sentence}")
    for problem, fixed in problems:
        print(f"NG  {sentence}\n    {problem} -> {fixed}")
