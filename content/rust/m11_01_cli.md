@@text
Rust is one of the best languages for command-line tools: a single fast binary with no runtime to install. ripgrep, fd, bat, eza, starship, zoxide, uv and many more are written in Rust. This lesson covers what makes a CLI tool pleasant and reliable, from argument parsing to exit codes.

## Anatomy of a good CLI

- **Arguments**: positional (`grep PATTERN FILE`), flags (`-v`, `--verbose`), options with values (`-n 5`, `--count=5`), subcommands (`git commit`, `cargo build`).
- **Help**: `--help` and `-h`, `--version`; errors that say what was wrong and how to fix it.
- **Streams**: read from **stdin** when no file is given; write results to **stdout** and messages/errors to **stderr**, so `tool | other-tool` works and errors still reach the screen.
- **Exit codes**: `0` success, non-zero failure (`1` general error, `2` usage error by convention). Scripts and CI rely on them.
- **Configuration**: flags beat environment variables beat config files beat defaults.
- **Be quiet by default**, colourful only on a terminal (respect `NO_COLOR`), machine-readable output on request (`--json`).

## clap: the standard argument parser

```rust,norun
// Cargo.toml: clap = { version = "4", features = ["derive"] }
use clap::{Parser, Subcommand};

/// Find large files and summarise folders
#[derive(Parser)]
#[command(version, about)]
struct Cli {
    /// Show more output
    #[arg(short, long)]
    verbose: bool,
    #[command(subcommand)]
    command: Command,
}

#[derive(Subcommand)]
enum Command {
    /// List the biggest files
    Top {
        path: std::path::PathBuf,
        #[arg(short = 'n', long, default_value_t = 10)]
        count: usize,
    },
    /// Total size per extension
    Summary { path: std::path::PathBuf },
}

fn main() {
    let cli = Cli::parse();      // prints help/errors and exits by itself
    match cli.command {
        Command::Top { path, count } => { /* ... */ }
        Command::Summary { path } => { /* ... */ }
    }
}
```

The doc comments become the help text. clap validates types, generates `--help`, suggests corrections for typos and can generate shell completions (`clap_complete`). For tiny tools, `std::env::args()` and a hand-written parser (the first exercise) is enough and compiles faster; `lexopt` and `argh` are light alternatives.

## Errors and exit codes

```rust,norun
fn main() -> std::process::ExitCode {
    match run() {
        Ok(()) => std::process::ExitCode::SUCCESS,
        Err(e) => {
            eprintln!("error: {e:#}");     // to stderr
            std::process::ExitCode::from(1)
        }
    }
}
```

Keep `main` tiny: parse arguments, call `run(config) -> Result<(), Error>`, and turn errors into a message and an exit code. With **anyhow**, `main() -> anyhow::Result<()>` prints the error and its causes and exits with 1; add context with `.with_context(|| format!("reading {path:?}"))`.

## Reading input efficiently

```rust,norun
use std::io::{self, BufRead, Write};

let stdin = io::stdin().lock();
let mut out = io::BufWriter::new(io::stdout().lock());
for line in stdin.lines() {
    let line = line?;
    writeln!(out, "{}", line.to_uppercase())?;
}
```

Lock stdout once and buffer it; Rust's stdout is line-buffered and locking per `println!` is slow for big outputs. When stdout is a closed pipe (`tool | head`), writes fail with `BrokenPipe`: treat it as a normal exit.

Accept both files and stdin with one function that takes `impl BufRead`, so it's also easy to test with `"text".as_bytes()`.

| Testing the binary | `assert_cmd` + `predicates` + `tempfile` |
| Distribution | `cargo install`, `cargo-dist` (builds installers and GitHub releases), Homebrew, winget, Scoop |

## Design checklist

1. Can it be used in a pipe? (stdin/stdout, no prompts when not a terminal)
2. Does `--help` explain every option with an example?
3. Are destructive actions behind `--force` or a confirmation, with a `--dry-run`?
4. Do errors name the file and the fix?
5. Is the exit code meaningful?
6. Is there a machine-readable output mode?

@@solution
#[derive(Debug, PartialEq)]
struct Config {
    count: usize,
    reverse: bool,
    exts: Vec<String>,
    path: String,
}

fn parse_args(args: &[&str]) -> Result<Config, String> {
    let mut count = 10;
    let mut reverse = false;
    let mut exts = Vec::new();
    let mut positional = Vec::new();
    let mut it = args.iter();
    while let Some(&a) = it.next() {
        match a {
            "-n" | "--count" => {
                let v = it.next().ok_or(format!("{a} needs a value"))?;
                count = v.parse::<usize>().map_err(|_| format!("{a}: not a number: {v}"))?;
                if count == 0 {
                    return Err(format!("{a} must be at least 1"));
                }
            }
            "-r" | "--reverse" => reverse = true,
            "--ext" => {
                let v = it.next().ok_or(format!("{a} needs a value"))?;
                exts.push(v.to_string());
            }
            _ if a.starts_with('-') => return Err(format!("unknown option: {a}")),
            _ => positional.push(a.to_string()),
        }
    }
    if positional.len() != 1 {
        return Err(format!("expected exactly one PATH, got {}", positional.len()));
    }
    Ok(Config { count, reverse, exts, path: positional.remove(0) })
}

fn main() {
    println!("{:?}", parse_args(&["-n", "3", "--ext", "rs", "src", "--ext", "toml", "-r"]));
    println!("{:?}", parse_args(&["-x", "src"]));
    println!("{:?}", parse_args(&["--count"]));
}

use std::io::BufRead;

#[derive(Debug, PartialEq, Default)]
struct Counts {
    lines: usize,
    words: usize,
    bytes: usize,
}

fn count(mut input: impl BufRead) -> std::io::Result<Counts> {
    let mut buf = String::new();
    let mut c = Counts::default();
    loop {
        buf.clear();
        let n = input.read_line(&mut buf)?;
        if n == 0 {
            break;
        }
        c.lines += 1;
        c.bytes += n;
        c.words += buf.split_whitespace().count();
    }
    Ok(c)
}

fn report(c: &Counts, name: &str) -> String {
    format!("{:>4} {:>4} {:>4} {name}", c.lines, c.words, c.bytes)
}

fn main() {
    let text = "the quick brown fox\njumps over\nthe lazy dog\n";
    let c = count(text.as_bytes()).unwrap();
    println!("{}", report(&c, "fox.txt"));
}
