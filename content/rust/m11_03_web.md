@@lesson m11-web Web Services with Axum: HTTP, Routing, JSON and State
@@text
Rust web services are fast, use little memory, and catch whole classes of bugs at compile time. **Axum** (from the Tokio team) is the most popular framework; it builds on **Tokio** (async runtime), **hyper** (HTTP) and **tower** (middleware). This lesson explains HTTP from the bytes up, then shows how Axum maps onto it.

## HTTP in plain text

An HTTP/1.1 request is text:

```text
POST /api/tickets?priority=high HTTP/1.1
Host: helpdesk.local
Content-Type: application/json
Content-Length: 34

{"title":"VPN down","user":"maya"}
```

- **Request line**: method, path (with optional `?query`), version.
- **Headers**: `Name: value` lines, ended by an **empty line**.
- **Body**: exactly `Content-Length` bytes (or chunked).

The response has a status line (`HTTP/1.1 201 Created`), headers and a body. Status codes: **2xx** success (200 OK, 201 Created, 204 No Content), **3xx** redirect, **4xx** client error (400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 409 Conflict, 422 Unprocessable), **5xx** server error.

**REST** conventions: resources as nouns (`/tickets`, `/tickets/42`), methods as verbs (`GET` read, `POST` create, `PUT`/`PATCH` update, `DELETE` remove), JSON bodies, status codes that mean something.

## An Axum service

```rust,norun
// Cargo.toml: axum = "0.8", tokio = { version = "1", features = ["full"] },
//             serde = { version = "1", features = ["derive"] }, serde_json = "1"
use axum::{
    Json, Router,
    extract::{Path, Query, State},
    http::StatusCode,
    routing::get,
};
use serde::{Deserialize, Serialize};
use std::sync::{Arc, Mutex};

#[derive(Clone, Serialize)]
struct Ticket { id: u32, title: String, done: bool }

#[derive(Deserialize)]
struct NewTicket { title: String }

#[derive(Deserialize)]
struct ListQuery { done: Option<bool> }

#[derive(Clone, Default)]
struct AppState { tickets: Arc<Mutex<Vec<Ticket>>> }

async fn list(State(s): State<AppState>, Query(q): Query<ListQuery>) -> Json<Vec<Ticket>> {
    let all = s.tickets.lock().unwrap();
    Json(all.iter().filter(|t| q.done.is_none_or(|d| t.done == d)).cloned().collect())
}

async fn create(State(s): State<AppState>, Json(body): Json<NewTicket>)
    -> Result<(StatusCode, Json<Ticket>), (StatusCode, String)> {
    if body.title.trim().is_empty() {
        return Err((StatusCode::UNPROCESSABLE_ENTITY, "title is required".into()));
    }
    let mut all = s.tickets.lock().unwrap();
    let t = Ticket { id: all.len() as u32 + 1, title: body.title, done: false };
    all.push(t.clone());
    Ok((StatusCode::CREATED, Json(t)))
}

async fn get_one(State(s): State<AppState>, Path(id): Path<u32>) -> Result<Json<Ticket>, StatusCode> {
    s.tickets.lock().unwrap().iter().find(|t| t.id == id).cloned().map(Json).ok_or(StatusCode::NOT_FOUND)
}

#[tokio::main]
async fn main() {
    let app = Router::new()
        .route("/tickets", get(list).post(create))
        .route("/tickets/{id}", get(get_one))
        .with_state(AppState::default());
    let listener = tokio::net::TcpListener::bind("127.0.0.1:3000").await.unwrap();
    axum::serve(listener, app).await.unwrap();
}
```

How it fits together:

- **Router**: maps method + path pattern to a **handler** (an async fn). `{id}` captures a path segment.
- **Extractors** are handler parameters that pull data out of the request: `Path`, `Query`, `Json` (deserialised body), `State`, `HeaderMap`. If extraction fails (bad JSON, wrong type), Axum answers 400/422 automatically and your handler never runs.
- **Responses**: anything implementing `IntoResponse`: `Json(value)`, `String`, `StatusCode`, tuples `(StatusCode, Json<T>)`, and `Result<A, B>` where both sides are responses.
- **State**: shared data (a database pool, config) cloned into each handler; wrap mutable parts in `Arc<Mutex<..>>`, or better, use a real database.
- **Middleware** from `tower-http`: `TraceLayer` (request logging), `CorsLayer`, `CompressionLayer`, `TimeoutLayer`, rate limiting; added with `.layer(...)`.

## Errors done properly

Define one `AppError` enum and `impl IntoResponse for AppError` that maps each variant to a status code and a JSON error body. Handlers then return `Result<Json<T>, AppError>` and use `?` freely (with `From` conversions from database and validation errors). Never leak internal error details (SQL, file paths) to clients; log them instead.

use std::collections::HashMap;

#[derive(Debug)]
struct Request {
    method: String,
    path: String,
    query: HashMap<String, String>,
    headers: HashMap<String, String>,
    body: String,
}

fn parse_request(raw: &str) -> Result<Request, String> {
    if raw.trim().is_empty() {
        return Err("empty request".into());
    }
    let (head, body) = raw.split_once("\r\n\r\n").unwrap_or((raw, ""));
    let mut lines = head.split("\r\n");
    let first: Vec<&str> = lines.next().unwrap_or("").split_whitespace().collect();
    let [method, target, _version] = first.as_slice() else {
        return Err("bad request line".into());
    };
    let (path, qs) = target.split_once('?').unwrap_or((*target, ""));
    let mut query = HashMap::new();
    for pair in qs.split('&').filter(|p| !p.is_empty()) {
        let (k, v) = pair.split_once('=').unwrap_or((pair, ""));
        query.insert(k.to_string(), v.to_string());
    }
    let mut headers = HashMap::new();
    for line in lines {
        if let Some((k, v)) = line.split_once(':') {
            headers.insert(k.trim().to_lowercase(), v.trim().to_string());
        }
    }
    let mut body = body.to_string();
    if let Some(len) = headers.get("content-length").and_then(|v| v.parse::<usize>().ok()) {
        body.truncate(len.min(body.len()));
    }
    Ok(Request { method: method.to_string(), path: path.to_string(), query, headers, body })
}

fn main() {
    let raw = "POST /api/tickets?priority=high&urgent HTTP/1.1\r\nHost: helpdesk.local\r\nContent-Type: application/json\r\nContent-Length: 15\r\n\r\n{\"title\":\"VPN\"}xx";
    let r = parse_request(raw).unwrap();
    println!("{} {}", r.method, r.path);
    println!("{:?} {:?}", r.query.get("priority"), r.query.get("urgent"));
    println!("{:?}", r.headers.get("content-type"));
    println!("{}", r.body);
    println!("{:?}", parse_request("GARBAGE\r\n\r\n").is_err());
}

Write a helper `fn match_path(pattern: &str, path: &str) -> Option<HashMap<String, String>>`: split both with `.split('/')`, return `None` if the counts differ; for each pair, if the pattern segment is `{name}` insert `name -> value`, else require equality. use std::collections::HashMap;

#[derive(Debug, PartialEq)]
enum Match {
    Found { route: String, params: HashMap<String, String> },
    MethodNotAllowed,
    NotFound,
}

struct Router {
    routes: Vec<(String, String, String)>,
}

fn match_path(pattern: &str, path: &str) -> Option<HashMap<String, String>> {
    let p: Vec<&str> = pattern.split('/').collect();
    let s: Vec<&str> = path.split('/').collect();
    if p.len() != s.len() {
        return None;
    }
    let mut params = HashMap::new();
    for (pat, seg) in p.iter().zip(s.iter()) {
        if pat.starts_with('{') && pat.ends_with('}') {
            if seg.is_empty() {
                return None;
            }
            params.insert(pat[1..pat.len() - 1].to_string(), seg.to_string());
        } else if pat != seg {
            return None;
        }
    }
    Some(params)
}

impl Router {
    fn new() -> Self {
        Router { routes: Vec::new() }
    }

    fn add(&mut self, method: &str, pattern: &str, name: &str) {
        self.routes.push((method.to_string(), pattern.to_string(), name.to_string()));
    }

    fn find(&self, method: &str, path: &str) -> Match {
        let mut path_matched = false;
        for (m, pattern, name) in &self.routes {
            if let Some(params) = match_path(pattern, path) {
                if m == method {
                    return Match::Found { route: name.clone(), params };
                }
                path_matched = true;
            }
        }
        if path_matched { Match::MethodNotAllowed } else { Match::NotFound }
    }
}

fn main() {
    let mut r = Router::new();
    r.add("GET", "/tickets", "list");
    r.add("POST", "/tickets", "create");
    r.add("GET", "/tickets/{id}", "show");
    r.add("GET", "/tickets/{id}/comments/{cid}", "comment");
    for (m, p) in [("GET", "/tickets/42"), ("GET", "/tickets/7/comments/3"), ("DELETE", "/tickets"), ("GET", "/users")] {

        }
    }
}
