@@lesson s12-tk-mvp Keep Logic Out of the Window: Model, View, Presenter
@@concepts objects, testing
@@text
In a beginner GUI, everything lives in button callbacks: they read entries, validate, update data, write files and change labels. It works until the app grows, and then nothing can be tested without clicking. The fix is to split the app into three parts, like the Rust GUI capstone did with its app state.

## Model, View, Presenter

```text
┌──────────┐   user events    ┌────────────┐   calls   ┌──────────┐
│   View   │ ───────────────▶ │ Presenter  │ ────────▶ │  Model   │
│ (Tkinter)│ ◀─────────────── │ (no Tk!)   │ ◀──────── │ (data &  │
└──────────┘   show(...)      └────────────┘  results  │  rules)  │
                                                        └──────────┘
```

- **Model**: the data and business rules (assets, tickets, validation, saving). Pure Python, no Tkinter.
- **View**: the window. It only creates widgets, forwards events to the presenter and displays what it's told. As dumb as possible.
- **Presenter**: decides what happens when the user does something: asks the model, then tells the view what to show. It talks to the view through a small interface (methods like `show_items`, `show_error`), never touching widgets directly.

Because the presenter doesn't import Tkinter, tests can give it a **fake view** that just records calls, and test the whole behaviour without a window. MVVM (WPF, the C# track) and the Elm architecture (Rust's iced) are variations of the same idea.

## An example

```python,norun
# model.py: pure logic
class Inventory:
    def __init__(self):
        self.assets = {}
    def add(self, tag, owner):
        if tag in self.assets:
            raise ValueError(f"{tag} already exists")
        self.assets[tag] = owner
    def search(self, text):
        t = text.lower()
        return sorted((tag, o) for tag, o in self.assets.items() if t in tag.lower() or t in o.lower())

# presenter.py: no tkinter import
class InventoryPresenter:
    def __init__(self, model, view):
        self.model, self.view = model, view
    def on_add(self, tag, owner):
        try:
            self.model.add(tag.strip().upper(), owner.strip())
        except ValueError as e:
            self.view.show_error(str(e))
            return
        self.view.clear_form()
        self.on_search("")
    def on_search(self, text):
        self.view.show_items(self.model.search(text))

# view.py: only widgets
import tkinter as tk
from tkinter import ttk, messagebox

class InventoryView(ttk.Frame):
    def __init__(self, master):
        super().__init__(master, padding=10)
        self.presenter = None
        self.tag, self.owner, self.query = tk.StringVar(), tk.StringVar(), tk.StringVar()
        ttk.Entry(self, textvariable=self.tag).grid(row=0, column=0)
        ttk.Entry(self, textvariable=self.owner).grid(row=0, column=1)
        ttk.Button(self, text="Add", command=lambda: self.presenter.on_add(self.tag.get(), self.owner.get())).grid(row=0, column=2)
        ttk.Entry(self, textvariable=self.query).grid(row=1, column=0, columnspan=3, sticky="ew")
        self.query.trace_add("write", lambda *_: self.presenter.on_search(self.query.get()))
        self.list = tk.Listbox(self, height=8)
        self.list.grid(row=2, column=0, columnspan=3, sticky="nsew")
    def show_items(self, items):
        self.list.delete(0, "end")
        for tag, owner in items:
            self.list.insert("end", f"{tag}  {owner}")
    def show_error(self, message):
        messagebox.showerror("Inventory", message)
    def clear_form(self):
        self.tag.set(""); self.owner.set("")

root = tk.Tk()
view = InventoryView(root); view.pack(fill="both", expand=True)
view.presenter = InventoryPresenter(Inventory(), view)
view.presenter.on_search("")
root.mainloop()
```

## Testing with a fake view

```python
class FakeView:
    def __init__(self):
        self.calls = []
    def show_items(self, items):
        self.calls.append(("items", items))
    def show_error(self, message):
        self.calls.append(("error", message))
    def clear_form(self):
        self.calls.append(("clear",))
```

Now `presenter.on_add("lt-1", "maya")` can be tested in microseconds: check that the model changed and the view was told to clear the form and show the new list. The exercises do exactly that.

## Rules of thumb

- If a function needs `tkinter`, it belongs in the view. If it contains an `if` about business data, it belongs in the presenter or model.
- The view never reads the model directly; it gets everything through the presenter.
- Keep presenter methods named after user intentions (`on_add`, `on_delete_selected`), not widgets (`button3_clicked`).
- Long operations: the presenter starts them in the background and updates the view when done (a later lesson).

class TicketPresenter:
    def __init__(self, model, view):
        self.model = model
        self.view = view

    def _refresh(self):
        rows = [f"#{tid} [P{t['priority']}] {t['title']}" for tid, t in self.model.open_tickets()]
        self.view.show_tickets(rows)

    def on_add(self, title, priority_text):
        try:
            priority = int(priority_text)
        except ValueError:
            self.view.show_error("Priority must be a number")
            return
        try:
            tid = self.model.add(title, priority)
        except ValueError as e:
            self.view.show_error(str(e))
            return
        self.view.clear_form()
        self._refresh()
        self.view.set_status(f"Added #{tid}")

    def on_close(self, selected_id):
        if selected_id is None:
            self.view.show_error("Select a ticket first")
            return
        try:
            self.model.close(selected_id)
        except KeyError:
            self.view.show_error(f"Ticket {selected_id} not found")
            return
        self._refresh()
        self.view.set_status(f"Closed #{selected_id}")

@@exercise Undo and redo
Desktop users expect Ctrl+Z. Implement the **command pattern** for the inventory model:

- `Inventory` holds `assets` (tag → owner) and two stacks.
- `do(command)` runs `command.apply(inventory)`, pushes it on the undo stack and clears the redo stack.
- `undo()` / `redo()` move the last command between stacks, calling `revert` / `apply`; they return the command's `describe()` text or `None` if there's nothing to undo/redo.
- `can_undo()` / `can_redo()` (to enable or disable menu items).
- Commands: `AddAsset(tag, owner)` and `Reassign(tag, new_owner)` (which must remember the old owner when applied). `describe()` returns `"add LT-1"` / `"reassign LT-1 to li"`.

`Reassign.apply` stores `self.old = inv.assets[self.tag]` before changing it; `revert` restores `self.old`. `AddAsset.revert` deletes the tag. `undo`: `if not self._undo: return None; cmd = self._undo.pop(); cmd.revert(self); self._redo.append(cmd); return cmd.describe()`.
@@solution
class Inventory:
    def __init__(self):
        self.assets = {}
        self._undo = []
        self._redo = []

    def do(self, command):
        command.apply(self)
        self._undo.append(command)
        self._redo.clear()

    def undo(self):
        if not self._undo:
            return None
        cmd = self._undo.pop()
        cmd.revert(self)
        self._redo.append(cmd)
        return cmd.describe()

    def redo(self):
        if not self._redo:
            return None
        cmd = self._redo.pop()
        cmd.apply(self)
        self._undo.append(cmd)
        return cmd.describe()

    def can_undo(self):
        return bool(self._undo)

    def can_redo(self):
        return bool(self._redo)


class AddAsset:
    def __init__(self, tag, owner):
        self.tag, self.owner = tag, owner

    def apply(self, inv):
        inv.assets[self.tag] = self.owner

    def revert(self, inv):
        del inv.assets[self.tag]

    def describe(self):
        return f"add {self.tag}"


class Reassign:
    def __init__(self, tag, new_owner):
        self.tag, self.new_owner = tag, new_owner
        self.old = None

    def apply(self, inv):
        self.old = inv.assets[self.tag]
        inv.assets[self.tag] = self.new_owner

    def revert(self, inv):
        inv.assets[self.tag] = self.old

    def describe(self):
        return f"reassign {self.tag} to {self.new_owner}"

inv.do(Reassign("LT-1", "li"))
