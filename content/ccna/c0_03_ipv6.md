@@lesson c0-ipv6 IPv6 Addressing and Configuration on IOS
@@text
CCNA expects you to read, shorten and configure IPv6 addresses, identify address types, calculate EUI-64 interface IDs, and configure IPv6 static routes. IPv6 is everywhere now (mobile networks, cloud, Japan's ISPs via IPoE), so this is job knowledge, not exam trivia.

## Format and shortening

128 bits, written as eight groups of four hex digits: `2001:0db8:0000:0000:0aa0:0000:0000:0001`.

Rules:
1. Drop **leading zeros** in each group: `2001:db8:0:0:aa0:0:0:1`.
2. Replace **one** run of consecutive all-zero groups with `::` (the **longest** run; if tied, the first): `2001:db8::aa0:0:0:1`.
`::` may appear only once, or the address would be ambiguous.

## Address types

| Type | Prefix | Notes |
|---|---|---|
| **Global unicast (GUA)** | `2000::/3` (2xxx, 3xxx) | public, routable; typically a /48 per site, /64 per subnet |
| **Unique local (ULA)** | `fc00::/7` (in practice `fd00::/8`) | private, like RFC 1918 |
| **Link-local** | `fe80::/10` | every IPv6 interface has one; not routed; used for neighbour discovery and routing protocol next hops |
| **Multicast** | `ff00::/8` | `ff02::1` all nodes, `ff02::2` all routers, `ff02::5`/`ff02::6` OSPFv3, `ff02::1:ffXX:XXXX` solicited-node |
| **Loopback** | `::1/128` | |
| **Unspecified** | `::/128` | |
| **Anycast** | from unicast space | the same address on several devices; nearest one answers |

IPv6 has **no broadcast**. Subnets are almost always **/64**: the first 64 bits are the prefix (global routing prefix + subnet ID), the last 64 the **interface ID**.

## EUI-64

Builds a 64-bit interface ID from a 48-bit MAC:

1. Split the MAC in half: `00:1a:2b` | `3c:4d:5e`.
2. Insert `ff:fe` in the middle: `00:1a:2b:ff:fe:3c:4d:5e`.
3. **Flip the 7th bit** (the U/L bit) of the first byte: `00` → `02`.
4. Result: `021a:2bff:fe3c:4d5e`.

So `2001:db8:1:1::/64 eui-64` on that interface gives `2001:db8:1:1:21a:2bff:fe3c:4d5e`.

## Address assignment

- **Static**: `ipv6 address 2001:db8:1:1::1/64`.
- **EUI-64**: `ipv6 address 2001:db8:1:1::/64 eui-64`.
- **SLAAC**: the router sends **Router Advertisements** (RA) with the prefix; hosts build their own address (EUI-64 or random/privacy).
- **Stateless DHCPv6**: SLAAC for the address, DHCPv6 for DNS and other options.
- **Stateful DHCPv6**: DHCPv6 hands out addresses (no default gateway though: that always comes from RAs).
- Hosts use **Duplicate Address Detection (DAD)** before using an address.

## NDP (Neighbor Discovery Protocol, ICMPv6)

Replaces ARP: **Neighbor Solicitation/Advertisement** (NS/NA, address resolution), **Router Solicitation/Advertisement** (RS/RA). `show ipv6 neighbors` is the IPv6 ARP table.

## Configuration on IOS

```text
R1(config)# ipv6 unicast-routing                     ! required for routing IPv6
R1(config)# interface g0/0
R1(config-if)# ipv6 address 2001:db8:10:1::1/64
R1(config-if)# ipv6 address fe80::1 link-local       ! optional, easier to read
R1(config-if)# no shutdown
R1(config)# ipv6 route 2001:db8:20::/48 2001:db8:10:1::2           ! recursive static
R1(config)# ipv6 route 2001:db8:30::/48 g0/1 fe80::3               ! directly attached + link-local next hop
R1(config)# ipv6 route ::/0 2001:db8:10:1::fe                      ! default route
R1# show ipv6 interface brief
R1# show ipv6 route
```

A static route with a **link-local** next hop must also name the **exit interface** (link-local addresses aren't unique across links).

@@solution
import ipaddress

addresses = ["2001:0db8:0000:0000:0000:ff00:0042:8329", "fe80::1", "2001:db8:0:0:1:0:0:1", "2001:db8:aaaa:bbbb:cccc:dddd:eeee:1", "::", "2001:0:0:1::1"]

def expand(addr):
    if "::" in addr:
        left, right = addr.split("::")
        left = left.split(":") if left else []
        right = right.split(":") if right else []
        groups = left + ["0"] * (8 - len(left) - len(right)) + right
    else:
        groups = addr.split(":")
    return ":".join(g.zfill(4) for g in groups)

def compress(addr):
    groups = [g.lstrip("0") or "0" for g in expand(addr).split(":")]
    best_start, best_len = -1, 0
    i = 0
    while i < 8:
        if groups[i] == "0":
            j = i
            while j < 8 and groups[j] == "0":
                j += 1
            if j - i > best_len:
                best_start, best_len = i, j - i
            i = j
        else:
            i += 1
    if best_len < 2:
        return ":".join(groups)
    left = ":".join(groups[:best_start])
    right = ":".join(groups[best_start + best_len:])
    return f"{left}::{right}"

for a in addresses:
    c = compress(a)
    ok = c == ipaddress.ip_address(a).compressed
    print(f"{expand(a)} -> {c} {'ok' if ok else 'MISMATCH'}")

import ipaddress

interfaces = [
    ("G0/0", "2001:db8:10:1::/64", "001a.2b3c.4d5e"),
    ("G0/1", "2001:db8:10:2::/64", "02:00:5E:10:00:01"),
    ("G0/2", "2001:db8:10:3::/64", "a4-6c-2a-ff-01-9b"),
]

def eui64(mac):
    digits = "".join(ch for ch in mac.lower() if ch in "0123456789abcdef")
    first = int(digits[:2], 16) ^ 0x02
    return int(f"{first:02x}{digits[2:6]}fffe{digits[6:]}", 16)

for name, prefix, mac in interfaces:
    iid = eui64(mac)
    net = ipaddress.ip_network(prefix)
    gua = ipaddress.IPv6Address(int(net.network_address) + iid)
    lla = ipaddress.IPv6Address(int(ipaddress.IPv6Address("fe80::")) + iid)
    print(f"{name}: {gua}  link-local {lla}")
